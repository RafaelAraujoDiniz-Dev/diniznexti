# DINIZ NEXTI

Site institucional da DINIZ NEXTI com foco em solucoes de tecnologia para residencias e empresas.

## Tecnologias
- HTML5
- CSS3
- JavaScript (vanilla)

## Visao geral
- Pagina inicial com servicos, depoimentos e contato.
- Galeria de servicos realizados com filtro por categoria e lightbox.
- Secao "Area atendida" com mapa e cidades proximas.
- Formulario de contato integrado ao Formspree.
- Botao de contato rapido via WhatsApp.

## Estrutura de pastas
- index.html
- servicos.html
- thanks.html
- style.css
- assets/
	- avatars/
	- cftv/
	- clients/
	- logo/
	- manutencao/
	- Salas/
	- servidores e redes/

## Como visualizar
Abra o arquivo index.html no navegador.

## Configuracoes importantes
- Formspree: ajuste o atributo data-endpoint no formulario (index.html).
- WhatsApp: ajuste o link https://wa.me/ no botao principal, se necessario.
- Mapa: o iframe usa Sao Luis/MA; altere o parametro na URL se quiser.

## Publicacao (GitHub Pages)
1. Envie todos os arquivos do projeto para o repositorio (incluindo assets/).
2. Ative o GitHub Pages em Settings > Pages.
3. Escolha a branch (geralmente main) e a pasta raiz.

## Manutencao
- Atualize conteudo e imagens em index.html e na pasta assets/.
- Ajuste estilos globais no arquivo style.css.
